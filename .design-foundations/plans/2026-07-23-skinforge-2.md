## Context

SkinForge는 마인크래프트 뚜따(얼굴 교체) 전문 웹 픽셀 에디터다. 현재 UI는 다크 회색 마인크래프트 인벤토리 스타일에 이모지 아이콘이 범람해 AI 생성물처럼 보이고 귀여움이 없다. 2.0에서는 라이트 파스텔 라벤더 팔레트 + 픽셀 폰트로 완전히 새로운 "귀여운 게임 도구" 정체성을 만들되, 포토샵식 레이아웃 구조와 모든 기능은 그대로 유지한다.

---

## Constraints

- 픽셀 폰트 필수 — Silkscreen (헤더/툴 이름); 10px 미만 라벨은 system sans-serif 혼용 (eye comfort 딜러핀)
- 이모지 금지 (SVG/Unicode 기호로 대체)
- 라벤더 포인트 컬러 (muted, 채도 낮음 — 눈 피로 방지)
- 라이트/파스텔 배경: 순백(#ffffff) 금지 → 따뜻한 크림/오프화이트
- 순검정 텍스트 금지 → 다크그레이 계열
- 포토샵식 레이아웃 구조 유지 (헤더 / 뷰어 / 캔버스 / 사이드패널)
- 기존 기능 전부 유지 (픽셀 에디터, 3D 뷰어, 팔레트, 머지 모달, 색상/색조 변경)
- 다크모드 불필요 (라이트 전용)
- 눈 편안함이 최우선: 오래 봐야 하는 도구

---

## Success Criteria

- 라벤더 포인트가 전체를 관통 (active 상태, 강조, 토글)
- Silkscreen 픽셀 폰트가 헤더/툴/버튼에 적용
- 이모지 0개
- WCAG AA 대비율 통과 (≥4.5:1 body, ≥3:1 large)
- AI-tells 없음 (Generic 패턴 제거, 의도적 선택이 명확)
- "귀여운 게임 도구" 느낌: 포토샵 구조 + 파스텔 라벤더 감성

### Phase 2: Design — DNA + Identity

**Stage:** Design
**Model:** fable
**Doctrine:** `design-dna`, `archetypes`, `foundations`, `fonts`, `color`, `ai-tells`
**Gate:** Full

**Goal:** SkinForge 2.0의 시각 정체성을 확립한다 — 라벤더 파스텔 + Silkscreen 픽셀폰트 + 눈 편안한 오프화이트 배경의 DNA를 5개 후보로 발산시키고 수렴해 DESIGN.md를 잠근다.

**Scope:**
- IN: 4개 축 (type voice, color strategy, composition, motion vocabulary) 전부, ai-tells 스캔, foundations 레지스터 설정, DESIGN.md 토큰 블록 생성
- OUT: 컴포넌트 스펙 (Phase 3), 코드 구현 (build)

**Constraints:**
- 딜러핀 (협상 불가): Silkscreen 픽셀폰트 헤더/툴; lavender 포인트; 라이트 배경; 이모지 금지
- 눈 편안함: 배경은 warm off-white (≈#f8f5f2 계열), 텍스트는 dark gray (≈#2a2a2a), lavender는 muted (채도 ≤60%)
- ai-tells 금지: 이모지 아이콘, Inter/system-ui as primary, 채도 높은 gradient, generic card grid
- 기준 레퍼런스 충돌 방향: "Game Boy Advance UI의 compact density + Animal Crossing의 warm pastel palette"

**Edge cases:**
- DESIGN.md 잠금 없이 Phase 3 진행 불가 — gate inversion 방지
- Silkscreen은 12px 이하에서 가독성 급락 — 최소 font-size 계획을 type scale에 명시해야 함
- muted lavender가 AA 대비율을 만족하는지 palette.mjs로 검증 필요

**Produces:** DESIGN.md locked (token block: 4 axes + semantic color tokens + type scale)
**Depends on:** Phase 1 (JOURNEY.md)
**Unlocks:** Phase 3

**Done when:**
- [ ] DW-2.1: DESIGN.md에 4개 축 모두 명시 (type voice, color strategy, composition, motion vocabulary)
- [ ] DW-2.2: DNA 수렴 근거가 기록됨 — 5개 후보, 각 후보의 reference collision (X의 [특정 품질] + Y의 [특정 품질]) 포함
- [ ] DW-2.3: ai-tells 스캔 통과 — 이모지 0, Inter/Roboto/system-ui as primary 0, 채도 높은 gradient 0
- [ ] DW-2.4: 모든 텍스트/배경 쌍이 WCAG AA 통과 (≥4.5:1 body, ≥3:1 large), palette.mjs 검증
- [ ] DW-2.5: 시맨틱 컬러 토큰 완성 (`--background`, `--surface`, `--text`, `--accent-solid`, `--accent-muted`)
- [ ] DW-2.6: type scale 완성 (`--text-xs`…`--text-2xl`), Silkscreen 사용 최소 임계값 명시

### Phase 3: Design — Token System + Component Specs

**Stage:** Design
**Model:** sonnet
**Doctrine:** `design-systems`, `usability`
**Gate:** Standard

**Goal:** DESIGN.md 토큰을 SkinForge의 모든 컴포넌트에 적용할 3-tier 토큰 시스템과 컴포넌트 스펙으로 확장해 build가 직접 구현할 수 있는 상태로 만든다.

**Scope:**
- IN: 3-tier 토큰 계층 (global → alias/semantic → component), atomic 컴포넌트 분해 (버튼, 입력, 스위치, 스와치, 패널, 모달, 툴버튼, 아이콘 슬롯), 눈 편안함 기준 컴포넌트별 적용
- OUT: 코드 구현, 실제 CSS/JSX 파일 수정 (build 단계)

**Constraints:**
- Prerequisite gate: DESIGN.md 잠금 확인 후 진행 (extend, never replace)
- 기존 CSS 변수 구조 (`--mc-*`)를 새 시맨틱 토큰으로 교체하는 마이그레이션 맵 필요
- 눈 편안함: hover/active 상태의 색상 변화는 급격하지 않게 (색상 변화 ≤20% lightness delta)
- 이모지 대체 아이콘 사양 — Unicode 기호 또는 inline SVG 목록으로 명시

**Edge cases:**
- 현재 `0.6rem` 이하 라벨들이 많음 — usability 기준으로 최소 font-size 재계산 필요
- `PixelEditor`, `SkinViewer3D`, `SkinMergeModal` 등 복잡한 컴포넌트는 surface 토큰만 적용하고 내부 canvas 렌더링은 건드리지 않음

**Produces:** Component specs (3-tier token table + atomic component map + icon replacement list)
**Depends on:** Phase 2 (DESIGN.md locked)
**Unlocks:** build

**Done when:**
- [ ] DW-3.1: 3-tier 토큰 표 완성 (global → alias → component), W3C DTCG 포맷 준수
- [ ] DW-3.2: Atomic 분해 완성 — atoms (버튼, 입력, 스와치, 아이콘, 레이블), molecules (툴버튼, 토글스위치, 팔레트슬롯), organisms (툴패널, 컬러패널, 헤더, 모달) 각각 명시
- [ ] DW-3.3: 이모지 대체 목록 완성 — 현재 이모지별 대체 Unicode 기호 또는 SVG 경로 명시 (✏️→ 펜 기호, 🪣→ 버킷 기호 등)
- [ ] DW-3.4: 기존 `--mc-*` 변수 → 새 시맨틱 토큰 마이그레이션 맵 완성
- [ ] DW-3.5: usability 기준 모든 인터랙티브 요소 target size ≥ 24×24px, 최소 font-size ≥ 11px 확인
- [ ] DW-3.6: 눈 편안함 기준 hover/active 상태 색상 delta ≤ 20% lightness 확인
