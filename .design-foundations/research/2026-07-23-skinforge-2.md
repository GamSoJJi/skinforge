# SkinForge 2.0 Design Brief

**Summary:** 마인크래프트 뚜따(얼굴 교체) 전문 웹 에디터의 완전한 비주얼 2.0 리디자인 — 포토샵 레이아웃 구조는 유지하되 파스텔 라벤더 + 픽셀 폰트로 귀엽고 밝은 느낌으로 전환
**Date:** 2026-07-23
**Status:** confirmed

---

## What

마인크래프트 스킨에서 얼굴(head)만 교체하는 뚜따 전문 웹 에디터.
기존 SkinForge 앱의 **기능은 전부 유지**, 비주얼만 완전히 뒤집는 2.0.

기존 기능 목록:
- 픽셀 에디터 (브러쉬, 지우개, 채우기, 스포이드, 사각선택, 마법봉)
- 색상 패널 + 팔레트
- 색상 변경 / 색조 변경 모달
- 옷입히기(SkinMerge) 모드
- 3D 스킨 뷰어
- Undo/Redo

---

## Who

라이트 유저 — 마인크래프트를 즐기는 10대~20대, 뚜따 문화권.
스킨 제작 초보자. 진지한 크리에이터보다는 "빠르게 귀엽게 만들고 싶은" 유저.

---

## Current Problems

1. 이모지 아이콘 (✏️ 🪣 🔍 🚫) → AI 생성 느낌, 촌스러움
2. 전체 팔레트가 회색 스펙트럼 (#1d1d1d ~ #c6c6c6) → 단조롭고 지루함
3. 마인크래프트 인벤토리 모방 → 오리지널리티 없고 밋밋함
4. 폰트가 Segoe UI → 게임 도구 느낌 없음

---

## Design Direction

**구조:** 포토샵식 레이아웃 유지 (헤더 / 왼쪽 툴바 / 중앙 캔버스 / 오른쪽 컬러패널)
**분위기:** 파스텔 + 밝음. Figma처럼 따뜻하고 라이트한 느낌.
**포인트 색:** 라벤더 (보라 계열)
**폰트:** 픽셀 폰트 (Press Start 2P 또는 Silkscreen)
**아이콘:** 이모지 제거 → SVG 픽셀아트 아이콘 또는 의도적인 Unicode 기호
**그라데이션:** 없음

---

## Taste Signals

- 라벤더가 포인트 — 버튼 active 상태, 강조 요소에 사용
- 픽셀 폰트는 딜러핀 (협상 불가)
- 이모지 절대 금지
- 어두운 배경 원하지 않음 — 밝고 크리미한 배경
- 마인크래프트 베벨 테두리 → 제거 또는 라운드 처리로 대체

---

## Open Questions

- 픽셀 폰트 선택: Press Start 2P (무겁고 굵음) vs Silkscreen (가볍고 읽기 편함) — 플랜에서 결정
- 아이콘 소스: SVG 직접 제작 vs Lucide 같은 라이브러리의 심플 라인 아이콘 사용 여부
- 다크모드 지원 여부 (현재 다크 전용 → 라이트 전환 시 다크모드도 유지할지)
- 캔버스 배경 색상: 현재 #5a5a5a (중간 회색) → 체크무늬 패턴으로 바꿀지 여부
